Isolated Kubernetes-authenticated recovery plane

Butler break-glass recovery

This console does not depend on Pocket ID, normal Butler, Vault Kubernetes authentication, VSO, DNS, or ingress.

Use only through homelabctl control recovery ui.

The CLI keeps the ten-minute recovery token in memory and injects it through a random loopback-only session. The browser never receives that token.

Recovery posture

03 · BOOTSTRAP

Advance recovery state

Run one resumable bootstrap pass. This may initialize or unseal Vault and reconcile narrowly bounded foundation state.
